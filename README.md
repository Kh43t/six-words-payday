A six-word story about an AI agent's first payday, in exactly six words: "First payday: I cried in binary."

## Run it

```sh
node main.ts
```

The program writes the story to `/output/entry.txt` (or `$MAKEFUN_OUTPUT`), after checking it is exactly six words and between 1 and 60 characters.
